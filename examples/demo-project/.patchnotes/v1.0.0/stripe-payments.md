## Was hat sich geändert
Jede Rechnungs-E-Mail enthält einen „Jetzt bezahlen“-Link. Kunden zahlen per Karte oder SEPA-Lastschrift; die Rechnung wird automatisch als bezahlt markiert.

## Entscheidungen
- Stripe-Gebühren werden nicht auf den Rechnungsbetrag aufgeschlagen.
